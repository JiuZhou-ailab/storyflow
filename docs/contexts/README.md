# Domain contexts

- `runtime-domains/` defines application conversation and project-work ownership boundaries.
- `skills-ecosystem/` defines global/project Agent Skill scope, the project-owned Skills marketplace, and host integration.
- `model-access/` separates persisted account identity, transient managed-model capability, and user-owned provider credentials.
- `tool-access/` separates installable methods, local capability projection, cloud tool routing, and provider tool credentials.
