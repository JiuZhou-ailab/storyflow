## 故事摘要（给编剧与制作团队）

顾清妍曾经相信，只要把事实核验清楚，真相就会自己站起来。她在星火传媒做事实核验编辑时，拒绝删掉一宗事故的前因后果，结果被公司推出去承担责任，离开了原来的工作。多年后，她回到父亲顾德安经营的法律援助中心，本想过一种安静的生活，却在社区服务大厅遇见了外卖骑手唐小芮：唐小芮正被逼着签下一份“自愿赔付”单，顾清妍伸手挡住保安和即将倒下的金属架，偏偏这一刻被剪成了一段十五秒的“暴力视频”。一夜之间，她从核验事实的人变成了被公众定罪的人。

为了证明自己没有伤人，顾清妍不得不重新进入自己最熟悉、也最厌恶的世界。她找上懂监控设备却不愿再惹麻烦的周野，与不愿再相信任何机构的唐小芮组成一个临时小组。他们接到的每一个求助，都有一个看似已经结束的结论：被封号的骑手被说成态度恶劣，被商场推责的保洁员被说成安全隐患，被差评逼到关店的小商户被说成危险商家，甚至连一个孩子的沉默也被剪成可以售卖的“亲子感动”。顾清妍要做的不是替每个人喊冤，而是陪他们把被删掉的时间、合同、工资、证人和选择一件件找回来。

案件越办越多，三个人发现这些冲突并不是偶然。不同平台、商场、商户和项目里，反复出现同一套剪辑模板、同一组客户编号和同一种“先让公众愤怒、再让当事人私下闭嘴”的处理方式。幕后是星火传媒的创始人裴峥，以及依靠这套舆情外包推进赔偿压缩、商户清理和城市更新的盛鼎城市服务集团。裴峥不需要把每个人都打倒，他只需要让证据晚一点出现，让解释听起来不够简单，让被害者在失去收入和安全之后主动签下封口协议。

真正的转折发生在团队开始争论“真相应该公开到什么程度”之后。面对未成年人小安的影像，顾清妍第一次主动放弃最容易传播的证据；面对自己的旧案，她也不能再把自己写成毫无瑕疵的受害者，因为她曾经为了保住工作沉默了七天。姜曼从星火内部带出的发票、报价单和主素材库索引，让团队终于看见这套生意的完整轮廓，但也迫使她承认自己曾经参与其中。最后的公开听证不是一次更大的直播打脸，而是一次关于谁有权解释证据、谁有权决定披露边界的争夺。

故事结尾，裴峥失去对叙事的控制，盛鼎承担项目责任，顾清妍却没有把胜利归功于一条爆款视频。顾德安的援助中心重新开放，变成由当事人共同参与的社区证据站：有人可以选择公开，有人可以选择保护隐私，但没有人再只能接受别人剪好的那十五秒。新当事人带来一段尚未看完的手机视频，顾清妍问的也不再是“要不要上热搜”，而是“你希望哪些部分被看见”。

这是一部关于“如何重新获得发言权”的短剧。制作上，每集都从一个已经被判断的现场切入，再把观众带进人物的生活成本、证据压力和关系选择；爽点来自一个人终于能在公开程序里说完整，而不是靠更大的辱骂或更猛烈的肢体冲突赢回来。以下内容按“人物与规则 → 故事引擎 → 篇章总纲 → 分集细纲 → 单集写作卡 → 连续性台账”的顺序组织，供编剧、导演、制片和后期共同使用。

### 1.1 一句话钩子

一段剪掉前因后果的十五秒视频，可以毁掉一个普通人的生活；只有找回“后半段”，才能让真相重新进入公共程序。

### 1.2 Logline

前平台事实核验编辑顾清妍回到父亲经营的法律援助中心，在社区服务大厅替外卖员唐小芮阻止一次强迫签字，却被剪成“暴力闹事者”。她与唐小芮、监控维修工程师周野组成“完整画面”小组，逐案帮助被舆论定罪的普通人找回原始证据，最终揭开星火传媒为企业制造冲突、操纵公众判断、掩盖现实责任的叙事工厂。

### 1.3 核心命题

> 谁控制了上下文，谁就控制了公众眼中的“正义”。

网络曝光只能带来注意力；真正的兑现必须经过证据、当事人选择、责任认定和现实补偿。

## 2. 主题与故事引擎

### 2.1 社会议题

- 断章取义与网络暴力；
- 平台算法对零工劳动者的单向定性；
- 企业用舆情外包转移劳动安全和赔偿责任；
- 小商户在虚假评价和城市更新中的生存压力；
- 未成年人隐私被包装成流量产品；
- 弱者举证、证人恐惧与公共程序的可达性。

### 2.2 核心冲突链

`错误指控 → 当事人被迫选择 → 对手加码控制 → 主角寻找证据 → 证据被反制 → 当事人决定披露边界 → 权力关系改变 → 暴露更大的主线线索`

### 2.3 主线升级

1. 名誉受损；
2. 收入和账号被夺；
3. 证人被合同与资源压制；
4. 商铺、居所和援助中心受到腾退威胁；
5. 公开听证和公共服务被同一套叙事机制接管；
6. 主角把个人翻盘变成可复核的公共证据流程。

### 2.4 单集推进规则

每集都要明确：

- 谁想得到什么；
- 谁或什么规则阻止他；
- 他采取了什么可拍动作；
- 行动造成什么立即后果；
- 结尾留下哪个具体问题。

禁止用“她很委屈、他十分愤怒、气氛紧张”替代行为。优先写收回手机、挡住窗口、翻到合同最后一页、删除录音、把未签字的笔推回去等可见动作。

## 3. 主要人物

### 3.1 顾清妍｜主角

- 30 岁，前星火传媒事实核验编辑。
- 曾因拒绝删减一宗事故的完整上下文而被迫离职。
- 起点目标：找回自己的原始视频，证明自己没有暴力伤人。
- 深层目标：建立普通人可以使用的证据和纠错流程。
- 缺陷：相信“证据够完整，公众自然会改变看法”，低估再次曝光对受害者的伤害。
- 能力：识别剪辑断点、叙事诱导和证据缺口；能把复杂材料拆成可理解的因果链。
- 边界：不是律师、警察、黑客或法医；法律程序由顾德安及正式机构完成。
- 终局变化：从“证明我没错”转为“让当事人决定哪些真相可以被看见”。

### 3.2 唐小芮｜共同主角

- 24 岁，外卖骑手，熟悉配送路线、平台申诉和骑手互助网络。
- 起点目标：解封账号、拿回工资、证明自己不是“碰瓷者”。
- 深层目标：让下一个骑手不用靠跪求或自证清白才能拿到应得的钱。
- 缺陷：不信任机构，习惯先忍下来换取即时收入。
- 成长：从提交证据的当事人，成长为组织现场证人、保护隐私并主持授权的人。
- 边界：不是技术专家；她的优势始终是现场经验、人际网络和行动勇气。

### 3.3 周野｜证据工程师

- 29 岁，监控设备维护工程师，熟悉存储、时间同步、备份和维修单。
- 起点目标：保住工作，不再卷入舆论案件。
- 深层目标：弥补自己曾按指令校准显示时间、间接帮助掩盖事故的过错。
- 缺陷：把“技术中立”当作逃避选择的理由。
- 成长：从只交付文件，成长为解释证据链、承担公开证人风险的人。
- 边界：不是万能黑客；任何恢复都必须有设备、权限和时间成本。

### 3.4 裴峥｜主要对手

- 36 岁，星火传媒创始人。
- 信念：公众不愿理解完整真相，只愿意站队；谁先定义情绪，谁就赢。
- 目标：扩大危机公关业务，拿下盛鼎城市服务集团的城市更新合同。
- 恐惧：公众重新要求上下文，自己的生意就失去效率。
- 策略：不一定销毁证据，而是让证据晚到、难懂、代价高；优先攻击主角可信度。
- 终局：在客户、证人和公开程序面前失去解释权，承担商业与法律后果。

### 3.5 姜曼｜灰度角色

- 33 岁，星火传媒公关总监。
- 起点立场：认为自己只是包装客户风险，不负责事实本身。
- 变化触发：发现公司把未成年人和普通劳动者当成可消耗的流量素材。
- 行动路线：先交出发票和报价，再交出模板、客户记录和主素材库索引。
- 代价：失去职业、人际信任，并必须承认自己参与过伤害。
- 禁止洗白：她的倒戈不能抹掉前期责任，也不能一次性解决所有证据问题。

### 3.6 顾德安｜规则角色

- 58 岁，完整画面法律援助中心负责人，顾清妍父亲。
- 价值：程序、授权、补偿和当事人的选择权。
- 与女儿的张力：他担心追逐真相会伤害当事人，她担心不公开会让机构继续作恶。
- 终局变化：从保护女儿的旧式援助中心，转为支持社区证据站的制度建设者。

## 4. 世界观与规则

### 4.1 完整画面法律援助中心

老城区临街二层的小型援助中心。资源少，但保存纸质授权、认识社区居民，愿意陪当事人完成申诉和责任程序。

空间弧线：

`狭窄办公室 → 被暂停补贴 → 被列入腾退 → 档案被查封/带走 → 重新开放为社区证据站`

### 4.2 星火传媒

表面是短视频运营和危机公关公司，实际出售“舆情定性”服务。

业务链：

`客户提出责任风险 → 寻找可传播冲突片段 → 先发短剪辑 → 组织情绪标签 → 逼迫私下和解 → 删除或稀释后续证据`

内部模板：

1. 15 秒内让观众形成单一判断；
2. 不让观众同时看到双方完整动机；
3. 解释晚于第一轮情绪扩散；
4. 当事人签署保密或撤诉协议后，案件才算“关闭”。

### 4.3 盛鼎城市服务集团

拥有物业、商业运营和城市更新项目，是星火的长期客户。它通过外包舆情降低赔偿、压低员工责任、清理旧商户并推进腾退。

### 4.4 证据规则

本剧不使用“主角一眼看穿真相”的魔法推理。证据至少来自两类，并尽量形成三点交叉验证：

- 原始影像：监控、手机视频、录音；
- 元数据：时间、设备、文件哈希、操作日志；
- 现实记录：订单、工资、合同、维修单、申诉编号；
- 证人证言：说明证人的利益、恐惧和可见范围；
- 程序动作：授权、调取、存证、公开、申诉、听证。

未经当事人同意，团队不能公开未成年人的正脸、住址或完整家庭影像。公开证据索引优先于公开全部原片。

## 8. 写标准剧本前的单集卡

每集先填写单集卡，再进入场次和对白：

| 字段 | 必填内容 |
|---|---|
| 集目标 | 本集结束时谁得到或失去什么 |
| 错误判断 | 观众前 5 秒会怎样理解现场 |
| 真实缺口 | 哪条证据、哪段关系或哪个规则被隐藏 |
| 主角选择 | 哪个角色做出不可逆行动 |
| 对手加码 | 对方如何让事情比上一集更难 |
| 可拍动作 | 手机、合同、门禁、窗口、设备、位置变化 |
| 状态变化 | 名誉、收入、关系、证据、空间、危险至少一项改变 |
| 集尾问题 | 下一集必须回答的具体问题 |

### 推荐单集节奏

`0–5 秒异常/指控 → 5–20 秒错误判断 → 20–55 秒行动与阻碍 → 55–80 秒证据或选择反转 → 80–100 秒代价与新问题`

压缩时长时压缩解释，不压缩行动、反应和后果。

## 9. 连续性台账（内嵌）

### 9.1 不可破坏事实

- 顾清妍不是律师、警察或黑客；她负责核验、信息拆解和策略。
- 唐小芮不是单纯受害者，也不是突然变成技术专家；她负责现场和社区网络。
- 周野所有技术恢复都有设备、权限和时间成本。
- 姜曼倒戈是渐进的；交出资料不能抹掉她早期责任。
- 裴峥控制的是叙事速度和解释权，不是所有现实机构。
- 未成年人隐私不能成为公开翻盘的牺牲品。
- 公开证据索引优先于公开全部原始素材。

## 11. 标准剧本扩写顺序

1. 先将 E01–E03 扩写为标准中文剧本，验证钩子、对白、证据和动作表达。
2. 做一次人物知识状态和角色命名审查。
3. 写完 E01–E15 后冻结第一篇章，再进入下一篇章。
4. 每 15 集完成一次因果、隐私、伏笔和角色状态审查。
5. 120 集正文完成后，再统一检查时间跨度、责任兑现和现实程序表达。
