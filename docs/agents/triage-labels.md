# Triage Labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不采取行动 |

Skill 提到角色时使用对应同名标签。复用已有标签，不改名、不删除仓库其他标签；现有 `ai-triage` 保持原有反馈流程用途，不自动映射为 `needs-triage`。
