# Repository agent guidance

## Agent skills

### Issue tracker

Specs 和 tickets 使用 `JiuZhou-ailab/storyflow` 的 GitHub Issues，通过 `gh` 操作。见 [issue tracker](docs/agents/issue-tracker.md)。

### Triage labels

使用五个默认 triage 标签，复用已有同名标签。见 [triage labels](docs/agents/triage-labels.md)。

### Domain docs

沿用现有 multi-context 布局及共享 ADR，不新建平行领域文档。见 [domain docs](docs/agents/domain.md)。
