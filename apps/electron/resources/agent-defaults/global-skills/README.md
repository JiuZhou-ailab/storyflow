# Bundled Skill Assets

- `find-skills/`：默认加载；从 Storyflow Skills Market 发现、审查并安装可复用能力。
- `firecrawl/`：默认加载；通过 Storyflow 托管的 `web_scrape` 提取单个动态网页正文，无需用户配置密钥。
- `skill-creator/`：默认加载；基于官方完整工作流创建、评测、审阅、迭代并验证 Storyflow Skills。
- `storyflow-tutorial/`：默认加载；介绍 Storyflow 的核心使用入口。
- `sn2s-novel-to-screenplay/`：默认加载；把小说转换为可续作、可校验的竖屏短剧分集项目。
