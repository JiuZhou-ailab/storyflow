# 剧情因果审查

## 核心原则

剧情逻辑不是检查“现实中是否可能”，而是检查文本内部是否建立了足够的因果、动机、信息来源、时间顺序和规则边界。先从原文无损抽取事实，再判断矛盾；不要用脑补替作者补桥。

## 审查流程

1. **抽取事实台账**
   - 人物已知：身份、目标、能力、关系、承诺、秘密。
   - 信息已知：谁在什么时候知道了什么，信息来自哪里。
   - 规则已知：世界观、能力、系统、法律、组织、资源限制。
   - 事件已知：按时间顺序列出关键行动和结果。
   - AI 初稿基础项：姓名、称谓、性别/身份、时间地点、物件状态、术语是否前后一致。

2. **建立因果链**
   - 每个关键事件是否由前一事件触发。
   - 每个转折是否有铺垫或可回溯依据。
   - 每次胜利、失败、误会、暴露是否有可解释原因。

3. **重建时间线**
   - 区分故事真实发生顺序、叙述呈现顺序、倒叙、插叙和未知空白。
   - 检查年龄、日期、持续时间、赶路、伤病恢复、信息传播速度是否匹配。
   - 检查原因是否发生在结果之前，角色是否基于尚未发生或尚未得知的信息行动。

4. **检查人物动机**
   - 角色行为是否符合其目标、利益、恐惧、认知和关系。
   - 是否为了剧情推进突然降智、沉默、冲动、圣母、恶毒。
   - 如果角色做出反常选择，文本是否给出足够压力或诱因。

5. **检查信息来源**
   - 角色是否知道了不该知道的信息。
   - 作者是否把旁白知识偷渡给角色。
   - 关键判断是否来自证据，而不是“他忽然明白了”。

6. **检查规则一致性**
   - 能力、道具、系统、组织权限是否前后一致。
   - 新规则是否只为解决当前困境临时出现。
   - 例外是否有代价、限制或明确边界。

7. **检查巧合和强行转折**
   - 巧合是否只负责制造麻烦，而不是解决麻烦。
   - 反转是否已有可回溯线索。
   - 救场是否来自主角选择、前文铺垫或可信外部力量。

8. **AI 初稿纠错**
   - 是否有人物叫错、关系错位、时间跳跃、地点混乱、称谓不统一。
   - 是否有基础文字错误影响理解。
   - 修复优先用最小改动；会改变剧情的修复只能列为建议。

## 严重度标准

- **P0 硬矛盾**：前后事实直接冲突，或角色知道不可能知道的信息。
- **P1 因果断裂**：关键转折缺少触发、铺垫或动机，读者会觉得作者硬推。
- **P2 可信度弱**：可以解释，但需要读者替作者补大量心理或设定。
- **P3 表达不清**：逻辑可能成立，但文本没有让读者顺利读出。

## 输出格式

```markdown
**因果结论**
一句话说明剧情是否自洽，以及最大风险。

**事实台账**
- 已确立事实：...
- 时间顺序：...
- 关键未知：...

**问题列表**
1. [P级别] 问题名：原文证据 -> 为什么断裂 -> 建议补哪一类桥。
2. ...

**最小修复路径**
1. 补信息来源 / 补动机 / 改事件顺序 / 增加代价 / 删除临时规则。
2. ...
```

## 常见误判

- 不要把“我能想象一种解释”当成文本已经完成解释。
- 不要要求所有设定都现实合理；只要求它们在作品内部稳定。
- 不要只说“不合理”；必须指出断在哪一环：动机、信息、规则、因果、时间线或代价。
- 不要用不断增加例外修复逻辑；优先调整前文铺垫、角色目标或事件顺序。
