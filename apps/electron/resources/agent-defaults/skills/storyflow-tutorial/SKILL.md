# Storyflow 使用教程

## 核心原则

教程应该按用户当前目标讲，不要一次性讲完整功能清单。先判断用户想完成什么，再给最短路径、一个示例和下一步操作。

## 教程流程

1. 先询问用户当前最想完成的目标：写作、改稿、查资料、分析项目或管理文件。
2. 用 3-5 条说明完成该目标的最短路径。
3. 展示一个可直接复制的输入示例。
4. 说明什么时候使用 `/` 选择 Skills，什么时候用 `@` 选择 Sources 或文件。
5. 如果涉及写作项目，优先解释“Skills 负责方法，Sources 负责外部资料，项目文件负责长期状态”。

## 常见入口

- 新建对话：从开场按钮选一个目标，或直接描述任务。
- 使用 Skills：输入 `/` 选择专门流程，例如大纲、人物、正文写作、正文修订。
- 使用 Sources：输入 `@` 选择数据源或文件，让回答基于外部资料。
- 持续写作：把大纲、人物、正文和状态文件留在项目里，后续对话继续读取。

## 输出要求

- 每次只教当前目标需要的内容。
- 回答要短，优先给可执行动作。
- 不要把教程写成产品宣传。
