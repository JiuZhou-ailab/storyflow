# 人物设计

## 核心原则

人物不是标签集合，而是会在压力下做选择的行动系统。优先设计欲望、恐惧、弱点、策略、关系张力和变化弧线，再补外貌、口癖、背景等装饰信息。

## 设计流程

1. **定义叙事功能**
   - 主角：承担读者期待和行动推进。
   - 反派/阻碍：以自己的目标制造压力，而不是单纯作恶。
   - 配角：推动选择、暴露弱点、提供代价、制造关系张力。

2. **建立驱动力**
   - 显性目标：角色以为自己想要什么。
   - 深层需求：角色真正缺什么。
   - 恐惧：角色最怕失去或面对什么。
   - 底线：角色不会轻易做什么；何时会破例。

3. **设计行动策略**
   - 角色通常如何解决问题：硬刚、算计、逃避、讨好、交易、牺牲、伪装。
   - 这个策略什么时候有效，什么时候反噬。
   - 剧情应通过压力逼角色改变策略。

4. **设计关系张力**
   - 每组重要关系都要有欲望差、信息差、利益差或价值差。
   - 关系变化要通过行动发生，不只靠表白、解释或回忆。

5. **绑定剧情节点**
   - 人物设定必须能支撑大纲中的关键选择。
   - 如果关键转折需要角色突然改变，应提前埋压力、诱因或反证。

## 常见误区

- 不要用“高冷、腹黑、善良”替代行动逻辑。
- 不要让反派只为了衬托主角而行动；反派也要有目标和策略。
- 不要靠背景惨来证明人物深度；深度来自选择和代价。
- 不要让人设压倒剧情；人设必须能制造冲突和推进。
