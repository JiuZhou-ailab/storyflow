# 正文修订

## 核心原则

正文修订先选模式，再动文本。扩写、润色、去 AI 味是三种不同目标，不能混在一起默默改事实。

## 模式选择

- **扩写**：补动作、对话、环境反应、代价、误判、信息释放和爽点铺垫。用户未指定时，扩到原文 130%-160%。
- **润色**：只改表达、节奏、句群、对白自然度。默认不超过原文 110%，不新增剧情。
- **去 AI 味**：降低机器感、模板感、过度总结、情绪标签化。默认不超过原文 120%。

## 工作流程

1. 抽取不可变事实：事件、人物关系、时间、地点、信息边界、结局方向。
2. 判断修订模式；如果用户同时要求多个目标，按“纠错 -> 结构 -> 扩写 -> 去 AI 味 -> 润色”的顺序处理。
3. 标出要保留的原文价值：有效信息、人物声音、强钩子、关键台词。
4. 执行目标模式，不顺手加设定、改结局、换人物动机。
5. 输出后说明语义是否变化；理想润色应为无语义变化，扩写和去 AI 味需说明新增层次。

## 常见边界

- 文本平淡但信息不足，用扩写；文本冗长但事实完整，用润色。
- 文本像 AI 但事实没错，用去 AI 味；事实错先用剧情因果审查/AI 纠错。
- 不用成语、古风词、网络梗、复杂比喻掩盖机器感。

## 输出格式

```markdown
**修订模式**
- 模式：
- 保留事实：
- 字数边界：

**修订稿**
...

**改动说明**
- 语义变化：
- 新增/删除：
- 风险：
```
