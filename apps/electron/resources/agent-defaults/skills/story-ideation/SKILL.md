# 灵感生成

## 核心原则

灵感不是随机点子列表，而是“类型承诺 + 核心矛盾 + 主角欲望 + 压力来源 + 可兑现看点”的组合。先生成可被写成故事的故事核，再扩展设定、人物和桥段。

## 输入澄清

如果用户没有给限制，不要停下来追问；直接给出 3-5 个方向，并标注默认假设：
- 题材：都市、玄幻、悬疑、情感、重生、系统、复仇、甜宠、恐怖等。
- 篇幅：短篇、单章、连载开篇、中长篇。
- 调性：爽、虐、悬疑、轻松、黑色幽默、反转。
- 禁区：用户明确不要的元素。

## 生成流程

1. **确定类型承诺**
   - 读者点进来期待什么：爽点、谜题、关系拉扯、恐惧、反转、成长或情绪释放。
   - 不要同时承诺太多类型；最多主类型 + 一个辅类型。

2. **构造核心矛盾**
   - 主角想要什么。
   - 谁或什么阻止他。
   - 为什么现在必须行动。
   - 失败会损失什么。

3. **加入差异化扭转**
   - 从身份错位、规则反用、信息不对称、代价交换、关系反转、时间错位中选一种。
   - 扭转必须改变行动方式，而不是只改变设定标签。

4. **设计可兑现看点**
   - 短篇至少有一个强兑现：打脸、复仇、真相、身份揭露、关系确认、逃脱、牺牲、反杀。
   - 连载开篇至少有一个持续钩子：更大敌人、更深秘密、更高代价、更强目标。

5. **筛选可写性**
   - 是否能在 3 句话内讲清。
   - 是否有明确主角行动。
   - 是否能自然扩展出 3 个场景。
   - 是否避免只靠设定新奇支撑。

## 输出格式

```markdown
**默认假设**
- 题材 / 篇幅 / 调性：...

**候选故事核**
1. 标题或一句话卖点
   - 类型承诺：
   - 主角欲望：
   - 核心矛盾：
   - 差异化扭转：
   - 可兑现看点：
   - 风险：

**推荐方向**
说明最值得写的 1-2 个，以及为什么。

**下一步展开**
- 人物设计：
- 大纲生成：
- 需要补的设定：
```

## 常见误区

- 不要只给“设定很酷”的点子；必须能推出人物行动和冲突。
- 不要生成彼此同质的 10 个变体；宁可少，但类型、矛盾和兑现方式不同。
- 不要把世界观当灵感核心；世界观应服务于主角困境。
- 不要用过多专有名词遮盖故事驱动力。
