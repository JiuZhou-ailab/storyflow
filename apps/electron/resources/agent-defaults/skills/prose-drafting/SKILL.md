# 正文写作

## 核心原则

正文写作只有两个入口：从“当前正文状态”继续，或从“已接受大纲/简报”执行。不要从宽泛一句话直接铺成正文；缺少故事核时先用灵感生成、大纲生成或网文短篇诊断补齐。

## 模式选择

- **续写模式**：已有正文、章节、片段，用户要求继续写、续章、接着写。
- **大纲转正文模式**：已有短篇大纲、章节计划、简报、beat sheet，用户要求生成正文。

## 工作流程

1. 无损抽取依据：人物、时间、地点、关系、已知信息、当前目标、阻碍、未解钩子、叙述视角。
2. 明确本次输出单位和长度。用户未指定时，续写默认不超过 1000 中文字；大纲转正文默认 800-1500 中文字。
3. 确定本段功能：开钩子、压迫、反击、反转、爽点、信息释放、章末钩子之一或两项组合。
4. 写正文时减少前情回顾；解释必须附着在动作、对话、证据或选择上。
5. 结尾制造继续阅读理由：新证据、新危险、新选择、新误会、更高代价或关系变化。

## 质量门槛

- 前 300-800 字必须出现处境、问题、冲突或不公平，不先铺世界观。
- 每 300-500 字至少有一次状态变化、阻碍升级或信息变化。
- 爽点前必须有痛点、代价或不公平；爽点必须来自人物行动或前文铺垫。
- 不突然新增设定解决问题，不改写已成立事实，不偷换人物动机。

## 输出格式

```markdown
**写作依据**
- 模式：续写 / 大纲转正文
- 当前状态：
- 本段功能：
- 长度假设：

**正文**
...

**假设与风险**
- ...
```
