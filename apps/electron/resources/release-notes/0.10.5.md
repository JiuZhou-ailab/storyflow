# 最新动态

Storyflow 0.10.5 让登录、会话恢复和工作区切换更稳定。更新后，邮箱账号可以直接完成验证，排队消息与历史会话也会按预期继续执行。

## 登录与账号

- **邮箱验证即可使用**：完成邮件验证后即可登录 Storyflow，不再依赖组织邀请；现有飞书登录保持不变。
- **Anthropic 授权自动返回**：浏览器授权完成后会自动回到 Storyflow，远程环境仍可粘贴授权码完成登录。

## Agent 与会话

- **历史会话恢复更一致**：Skills、模型调用、登录和历史记录使用同一套运行时，减少切换与恢复时的状态差异。
- **排队消息按顺序执行**：处理中追加的消息会按照提交顺序继续发送，避免后发消息提前执行。
- **Skill Creator 更稳定**：内置 Skill Creator 不再依赖外部 Agent CLI，Windows 环境也能直接使用。

## 工作区与交互

- **切换项目立即刷新配置**：工作区变化后会自动读取最新配置，无需重启应用。
- **复杂问题逐项回答**：结构化提问改为分页显示，较长的问题也能逐步完成。
- **正式版启动更可靠**：修复 Electron 打包后主进程无法正确定位运行资源而导致的启动失败。
