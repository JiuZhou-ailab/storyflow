# 最新动态

这一版写作更省心：正文自动保存，助手改过的文件直接生效，各种出错都能看到原因、可以重试。

## 这次更新

- **正文自动保存**：停下输入片刻就写入文件，不用再点保存。
- **不会互相覆盖**：你和助手同时改一份文件时，由你选择保留哪一版。
- **助手会先重读**：你在编辑器里改过的文件，助手下一轮会先读最新内容再动手。
- **更新须知**：版本历史、接受/拒绝、另存为和恢复副本已移除，原有数据仍留在电脑上。

## 写作

- **一份文件一份草稿**：写作视图和原文视图共用同一份内容，来回切换不会丢字。
- **跟随磁盘变化**：文件在别处被改过，切回窗口后会自动显示最新内容。
- **改动对照仍在**：助手改了哪些文件、增删了哪些文字，仍可在回复下方的改动摘要里查看。
- **只看不改不会动你的文件**：打开或切换视图不会改写 Markdown 的原有格式。

## 更稳

- **退出和更新更可靠**：退出检查有超时，窗口无响应时可以选择重新加载；安装更新前会先确认安装包完整。
- **失败可见可重试**：启动、打开项目或删除会话失败时会说明原因，并可以重试。
- **凭据文件更安全**：无法解密时先备份原文件，不再直接删除；写入改为原子写。
- **移除项目更安全**：项目的应用数据会移到备份目录，保留最近 5 份。
- **导出表格更准确**：正确处理单元格里的换行和特殊字符，导出和复制后会给出提示。

## 更新须知

- **版本历史与接受/拒绝已移除**：助手改了就是改了，需要可回溯的历史时，请用你自己的 Git 或同步盘管理项目文件夹。
- **原有数据不会删除**：旧版本在项目里创建的 `.git` 快照、以及恢复副本目录都原样保留，需要时仍可找回。
- **Windows 背景材质默认关闭**：如需毛玻璃效果，可在外观设置中打开。
