# 最新动态

Storyflow 0.17.0 让桌面会话、Skill 更新和长时间运行更稳定。

## 对话与工作区

- **编辑入口更顺畅**：从标签、权限等设置发起的 AI 编辑会正常创建并发送到对应会话。
- **Skill 更新即时生效**：安装或更新 Skill 后，当前工作区会自动刷新，不必重启应用。
- **会话恢复更可靠**：启动、重连和外部修改后，会话列表、元数据与磁盘内容保持一致。

## 安全与稳定性

- **外部链接更安全**：外部 `craftagents://` 链接仅保留需要用户确认的 Skill 安装入口，不会直接创建会话、发送消息或删除内容。
- **异常退出更易恢复**：服务锁会在正常退出时清理，并在异常中止后安全恢复，减少重复启动卡住的情况。
- **大输入更稳**：Skill 下载、Deep Link 和筛选配置受大小限制，避免异常数据拖慢应用。
