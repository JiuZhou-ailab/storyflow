# 最新动态

Storyflow 0.13.0 将联网搜索与网页内容提取纳入托管能力，并让研究型工作流更容易复用。

## 联网研究

- **搜索与网页提取更完整**：内置工具支持联网搜索和提取公开网页正文，减少手动切换外部工具的需要。
- **研究技能可直接安装**：Skills Market 新增联网研究技能，帮助拆分问题、查找来源并整理有依据的结果。
- **保留可用的搜索回退**：托管服务暂时不可用时，搜索仍可使用无凭证回退路径。

## 安全与稳定性

- **凭证边界更清晰**：第三方服务密钥只保留在托管 Worker，桌面端和子进程只持有短期、按操作授权的能力。
- **请求更可控**：搜索和网页提取分别限制请求大小、响应大小与调用频率，异常凭证不会直接暴露给客户端。

## 运行时体验

- **长任务状态更可靠**：Pi 运行时继续正确投影思考与工具事件，减少切换模型或继续任务时的状态错乱。
