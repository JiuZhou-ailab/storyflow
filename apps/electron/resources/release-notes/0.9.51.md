# 最新动态

这一版让 Storyflow 更专注于本地创作，并补齐 Agent 协作、Skills、更新提醒和托管模型稳定性。

## 创作工作区更清爽

- **本地项目直接可用**：桌面端本地工作区不再被账号登录挡住，账号能力与本地创作保持清晰边界。
- **空白会话只保留真正入口**：仅展示导入项目、新建项目和 Skills，不再出现无效的文件树与快捷操作。
- **工具过程自动收起**：执行时保持展开，完成后自动折叠；手动展开后会尊重用户选择。
- **侧边栏层级更清晰**：项目与会话形成稳定的两级结构，默认显示最近记录并可按需展开。

## Agent 协作

- **支持临时子 Agent**：主 Agent 可以按需启动独立子任务，并把结果收回当前对话，复杂工作不再挤在一条执行链里。

## Skills 更轻更开放

- **默认 Skills 更精简**：新工作区只默认加载发现和创建 Skills 所需的基础能力。
- **接入 SkillHub**：发现和发布 Skills 统一前往 SkillHub，移除旧市场开关和内置访问密钥。

## 更新不再悄悄消失

- **状态持续显示在侧栏**：下载中、等待重启和失败状态会一直保留在角落入口，直到用户完成处理。

## 托管模型连接

- **协议兼容更稳定**：托管模型默认使用所有当前模型都支持的 Chat Completions；网关继续保留 Responses 路由，待模型兼容性验证通过后再启用。
- **错误更容易定位**：空响应和协议转换失败会返回明确错误；日志记录请求耗时、上游状态、关联标识和飞书用户名称，不写入对话正文或访问凭据。
