# 最新动态

Storyflow 0.24.0 支持更换自由对话文件的存储位置，改善长会话恢复和文件编辑体验。

## 对话与文件

- **自由选择存储位置**：在应用设置中选择文件夹，下次启动时复制并校验自由对话文件，保留原目录备份。普通升级不会主动搬迁数据。
- **迁移中断后可恢复**：保留迁移进度，完成后直接使用新位置；再次启动不会重复复制已完成的数据。
- **文件操作更顺手**：标签栏加号可直接新建文件，文件树跟随当前文档高亮，并完善文件夹打开入口和链接错误提示。
- **稿件阅读更清晰**：调整正文行距，修复样式覆盖造成的显示不一致。

## 模型与长会话

- **保留原始会话内容**：更新 Agent 运行时，沿用原生历史恢复与上下文压缩；不再在启动时改写用户的 Pi 全局资源设置。
- **更新托管 Gemini 型号**：退役 Gemini 2.5、3.5、3.6、3.7 Flash。旧会话在账户已授权 Gemini 3.8 Flash 时使用该型号继续；未获授权时需选择账户内可用模型。用户自有模型连接不受影响。
- **连接与技能加载更稳定**：改善连接握手和认证网络诊断，减少重复的技能目录请求。

## 更新须知

已有稿件和原始会话历史会保留。新运行时的上下文记录不支持仅替换旧版应用来降级；需要回退时，应先保留升级后的数据，再成对恢复升级前的会话元数据和 Pi 历史备份，避免丢弃升级后产生的内容。
