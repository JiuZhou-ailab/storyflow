# 最新动态

Storyflow 0.14.0 让爆款短剧数据和 Skills 安装真正可用，同时修正首次对话的输入布局。

## 爆款短剧数据

- **独立数据源可以直接启用**：连接公司 VPN 后，即可查询红果、GoodShort、ReelShort 与 DataEye 的榜单、快照和媒资状态，无需填写访问凭据。
- **升级后自动衔接新入口**：已有安装会迁移内置数据源；连接公司 VPN 后重新启用即可使用，不会继续访问已经下线的旧入口。

## Skills

- **下载后可以正确导入**：Skills Market 会在发布前验证 Skill 格式，现有可安装内容也已修正为运行时能够识别的版本。
- **精选 Skill 安装更稳定**：修复两项精选 Skill 的下载校验，并确保免费会话把 Skill 安装到当前用户可发现的位置。

## 对话体验

- **首次输入栏排列正常**：移除首次对话工具栏中的多余占位，输入操作不再被错误间距挤开。
