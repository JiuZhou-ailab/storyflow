# 最新动态

这一版完善了 Storyflow 内置的 Skills 发现、安装、分享与管理体验。

## Skills

- **技能页成为统一入口**：“发现”和“已安装”现在使用独立标签页，可以直接搜索、安装、打开或发布，不再混在一个长页面中。
- **发现内容可以先看再装**：点击目录中的 Skill 即可查看完整说明；列表会根据人物、研究、世界观、故事结构等内容显示不同图标，并保留前往 SkillHub 的外部入口。
- **目录补充使用热度**：目录会显示每个 Skill 的下载次数并按热度排序，精选内容保持稳定，不会被重复下载改变。
- **公司共享更容易识别**：目录会显示真实发布者、公开或公司范围以及内容来源，支持按发布者名称搜索，团队成员可以更快找到彼此分享的 Skill。
- **已安装 Skills 可以管理**：已安装标签页会同时显示名称和说明并支持搜索；用户创建或安装的 Skill 可以从列表或详情页安全移除，Storyflow 自带的“查找 Skill”和“Skill Creator”会继续保留。
- **发布流程形成闭环**：上传后由 AI 自动检查并发布，发布服务、公司权限和安装包完整性都进入统一发布门禁。

## 模型连接

- **模型按各自协议运行**：托管模型分别使用对应的原生协议与能力配置，减少切换模型后出现请求参数不兼容的问题。
- **每轮用量更透明**：消息下方新增模型调用次数，可以区分一条用户消息与背后实际发生的模型请求；短暂网络故障由同一重试链路处理，不再重复叠加重试。
