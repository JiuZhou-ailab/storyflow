# 最新动态

这一版完善了 Storyflow 内置的 Skills 发现、安装、分享与管理体验。

## Skills

- **技能页成为统一入口**：同一页面集中展示已安装 Skills、精选目录和公司内部目录，可以直接搜索、安装、打开或发布，不再跳转到独立网页。
- **公司共享更容易识别**：目录会显示真实发布者、公开或公司范围以及内容来源，支持按发布者名称搜索，团队成员可以更快找到彼此分享的 Skill。
- **已安装 Skills 可以管理**：大量 Skills 默认折叠展示，用户创建或安装的 Skill 可以从列表或详情页安全移除；Storyflow 自带的“查找 Skill”和“Skill Creator”会继续保留。
- **发布流程形成闭环**：上传后由 AI 自动检查并发布，发布服务、公司权限和安装包完整性都进入统一发布门禁。

## 模型连接

- **模型按各自协议运行**：托管模型分别使用对应的原生协议与能力配置，减少切换模型后出现请求参数不兼容的问题。
