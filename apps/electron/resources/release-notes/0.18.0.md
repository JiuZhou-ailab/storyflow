# 最新动态

Storyflow 0.18.0 让项目管理、长对话和日常输入更顺手，也收紧了项目能力的授权边界。

## 升级提示

- **旧项目需要重新关联**：从 0.17.1 升级后，请为原有项目重新选择一次目录；项目身份、原文件和已有任务保持不变。
- **项目能力需要重新确认**：执行权限、项目本地 MCP、默认数据源和后台自动化不会沿用旧默认值，请在项目设置中按需开启。

## 项目与对话

- **重新添加项目不会动原文件**：已有配置和文件会完整保留，不再重置整个目录。
- **新项目创建后直接开聊**：新项目会出现在列表顶部，并自动打开新的对话页面，不再停在无对话状态。
- **长对话自动整理上下文**：达到上下文阈值后会自动整理历史并保留关键上下文，减少窗口占满造成的中断。

## 输入体验

- **输入栏更简洁**：附件和数据源统一收进“+”菜单，运行权限改用文字颜色区分。
