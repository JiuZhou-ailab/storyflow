# 最新动态

Storyflow 0.10.7 让对话、设置和 Skills 用起来更顺手：顶栏更轻，用量更清楚，精选写作 Skill 可以直接安装，Gemini 托管模型也更完整。

## 对话

- **聊天内容更顶格**：标题与菜单悬浮在左上角，不再挤占对话空间，窗口其余顶栏保持可拖动。
- **用量信息更克制**：单轮耗时和 Token 收进回复操作栏，当前项目的总用量统一在设置中查看。

## Skills

- **精选写作 Skill 可直接安装**：番茄写作、小说创作、评审、改编与分镜等精选能力现在通过固定版本包安装。

## 模型与稳定性

- **Gemini 选择更完整**：托管模型新增 Gemini 3.6 Flash、Gemini 3.1 Pro Preview、Gemini 2.5 Pro 与 Gemini 2.5 Flash。
- **长任务与旧会话更稳**：长时间推理不再过早中断，旧会话无法回退时会给出明确提示。

## 帮助与更新

- **帮助入口更集中**：新功能、教程和反馈统一放进侧栏帮助菜单，未读更新会显示蓝点。
