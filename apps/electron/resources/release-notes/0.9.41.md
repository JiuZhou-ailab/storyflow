# 最新动态

这一版让项目回到真实文件夹：不再由 Method Pack 预设目录和写作方法，Agent、侧边栏、审阅与导出统一以当前项目根目录为事实源。

## 项目与文件

- **新项目从空白开始**：创建项目不再要求选择方法，也不会预先生成目录、模板文件或 Git 仓库。
- **文件操作保持通用**：可以在当前目录直接新建文件、新建文件夹或导入文件，删除本地内容后侧边栏会反映真实状态。
- **空项目入口更直接**：可以描述目标、导入内容、新建文件或选择 Skill，不需要先理解 Storyflow 内部分类。

## Agent 与旧项目

- **Agent 始终工作在当前项目**：项目会话拥有明确的工作目录，相对路径统一落在当前项目根目录。
- **Skills 按需选择**：写作方法回到显式 Skill，不再和项目类型、目录结构或写入规则绑定。
- **旧项目无损兼容**：既有写作 manifest 仍可读取，但加载时不会补建、删除或重排用户文件。

## 审阅、导出与链接

- **审阅覆盖真实文件**：未知目录和文件类型不再因为旧写作分类而被忽略。
- **导出保留目录结构**：可以显式选择文件或文件夹，内容和相对路径保持不变。
- **对话文件链接可以直接打开**：本地 `file://` 链接会保留完整路径，不再退化成错误的相对路径。
