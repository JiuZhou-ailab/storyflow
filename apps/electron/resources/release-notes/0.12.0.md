# 最新动态

Storyflow 0.12.0 把短剧调研、项目创作和 Pi 运行时收敛到更清晰的边界，并让编辑、文件跳转和长任务更稳定。

## 短剧调研与创作

- **Catalog 成为内置数据源**：登录 Storyflow 后可查询红果、GoodShort、ReelShort 和 DataEye 的来源内榜单、历史快照和媒资覆盖；不同平台的统计口径保持独立，不会被混算。
- **选中剧目可继续转剧本**：媒资完整且传输形态受支持时，可取得有序分集清单并衔接视频转剧本流程。
- **项目命名跟随当前语言**：小说转剧本项目会按当前语言创建元数据、连续性、分集和剧本文件，旧项目仍按原有路径读取。

## 对话与编辑

- **编辑并重新生成更快、更稳**：重写消息会复用当前 Pi 运行时和独立的临时推理会话；主对话进行中也可立即开始，等待期间不会重复触发。
- **文件链接保持确定性**：AI 回复中的相对路径按对话工作目录解析；对话开始后不再临时切换目录，避免文件预览与工具执行指向不同位置。
- **Markdown 编辑基础统一**：写作编辑器统一使用官方 Markdown 引擎，减少双实现带来的格式差异，并收紧聊天消息的展示空间。

## 稳定性

- **Pi 上下文边界更清楚**：运行规则与每轮项目数据分开注入，动态路径不会污染稳定系统提示或持久对话历史。
- **Gemini 3 工具历史更可靠**：保留模型要求的思考签名，降低切换模型或继续工具调用时的请求失败。
- **长任务不再因暂时无事件而误停**：模型请求、工具和权限流程继续由各自运行时管理超时，会话层只保留绝对安全上限。
