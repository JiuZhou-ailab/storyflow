# 最新动态

这一版修复了写作编辑器的安全问题，也改进了项目切换、Skills 市场刷新和模型错误提示。

## 写作、项目与 Skills 市场

- **写作编辑器安全修复**：更新了处理 Markdown 内容的编辑器组件。
- **切回已打开的项目更快**：先显示上次加载的文件目录，再检查文件是否有更新。
- **随时刷新 Skills 市场**：可以主动刷新列表，加载失败后也可以直接重试。

## 聊天与模型

- **托管模型访问提示更明确**：应用会区分需要重新登录、权限已取消和服务暂时不可用，并在访问恢复后提示你重新发送消息。
- **紧凑聊天也能看到实际回复模型**：如果首选模型处于冷却期，聊天会说明这次为什么用了其他模型。
- **GPT 和 Gemini 会话更容易继续**：GPT 遇到会话里的推理内容失效时会尝试自动恢复，Gemini 继续带有工具调用记录的会话时更稳定。
- **模型服务临时故障可重试**：修复部分网关连接错误未按临时故障处理的问题。

## 自托管 Server

- **恢复 Server 镜像构建**：从源码构建镜像时，可以按锁文件安装依赖。
