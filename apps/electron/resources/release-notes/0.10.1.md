# 最新动态

Storyflow 0.10 是一次执行内核、会话体验与长篇写作工作区的整体升级。Agent 现在统一运行在 Pi 原生内核上，同时完成了会话切换、Skills、多任务进度和大型项目性能治理。

## 全新执行内核

- **统一到 Pi 原生运行时**：模型、工具、Skills 与会话执行走同一套原生能力，减少重复实现带来的状态分叉，长任务和工具调用更稳定。
- **模型连接更可靠**：OAuth 凭证、运行时配置与模型连接使用明确的所有权和加载顺序，降低重启、切换模型或恢复会话时的失效概率。
- **会话恢复可补偿**：跨项目迁移、回退与状态保存改为显式流程；即使中途失败，也不会静默落到错误会话或留下半完成状态。

## 会话与输入体验

- **切换会话后立即可输入**：输入框会正确获得焦点，`/` 命令和 `@` 菜单不会因共享引用被清空而失效。
- **中文语境也能唤起命令**：在中文句子中输入 `/` 仍可正常打开命令菜单，不再要求前面必须是英文空格。
- **导航状态更一致**：会话显示状态、窗口状态和配置写入采用统一且原子的顺序，减少重启后位置错乱或旧状态覆盖新状态。

## Skills 与多任务

- **精选 Skills 更容易识别**：重建精品推荐并统一内容图标，目录加载语义也与本地已安装状态保持一致。
- **子代理进度直接可见**：独立子代理的执行状态会在首层展示，不必展开多层记录才能确认任务是否仍在运行。

## 长篇写作与性能

- **大型目录恢复完整滚动**：数百章项目不再被容器裁掉，可以稳定滚动并打开深层章节。
- **减少无意义的重复渲染**：权限模式、缩略图、自动化历史等界面删除了重复状态同步，降低切换时的额外提交和旧数据闪现。
