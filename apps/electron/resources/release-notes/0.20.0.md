# 最新动态

Storyflow 0.20.0 接入 MCP 与 Skills Hub 客户端闭环，补充用量统计与市场能力，并加固历史数据保护。

## 新功能

- **项目用量统计**：新增项目用量活动统计，直观查看各项目的使用情况。
- **MCP 与 Skills Hub 闭环**：接入第三方 MCP 服务与 Skills 市场客户端，移除内嵌 Skills Registry，转向 Hub 管理。
- **MCP 市场入口**：MCP 数据源页新增市场入口，可查看服务端点并在明确确认后添加到本机。

## 搜索与编辑器

- **搜索范围更清楚**：左上角搜索会明确区分跨项目跳转与当前工作区内容，文件结果也会显示命中路径和位置。
- **Markdown 表格可编辑**：编辑器现在会正确解析、显示并保留 GFM 表格。

## 稳定性

- **修复闲置会话"思考中"不收尾**：会话闲置时思考状态不再残留。
- **锁定已开始会话的模型连接**：会话开始后锁定模型连接，避免中途切换导致行为不一致。
- **OpenAI 加密推理 400 自动恢复**：上游加密推理内容失效报 `invalid_encrypted_content` 时自动降级重试，不再中断对话。

## 数据安全

- **自定义 Catalog 资源保护**：升级时不再覆盖用户自定义的 Catalog 资源，并有备份与跨仓库契约门禁。

## 界面

- **主题与控件层次优化**：收敛全局主题与控件层次，压缩设置导航栏密度，增强边框与阴影层次。
- **macOS 窗口边缘收敛**：调整窗口边缘与标题栏补偿。
- **活动栏分隔线**：活动栏与内容区之间补充分隔线，边界更清晰。

## 数据源

- **短剧数据源更新**：内置「爆款短剧数据」现在提供 ReelShort、DramaBox 与 NetShort 的剧目、分集和播放数据。
