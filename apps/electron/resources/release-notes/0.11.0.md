# 最新动态

Storyflow 0.11.0 把短剧榜单调研正式接入 Sources，同时让多语言创作项目和长任务更稳定。

## 短剧调研

- **Catalog 成为内置数据源**：登录 Storyflow 后可查询红果、GoodShort、ReelShort 和 DataEye 的来源内榜单、历史快照和媒资覆盖。
- **榜单证据不会被混算**：查询保留每个平台的榜单口径、观测周期和原始指标，跨来源结果只并列展示，便于区分数据事实与分析推断。
- **选中剧目可继续转剧本**：媒资完整且传输形态受支持时，可取得有序分集清单并衔接视频转剧本流程。

## 语言与创作

- **回答和项目命名跟随当前语言**：对话标题、新建的用户可见文件、文件夹和 Skill 内容会使用选定语言，代码、配置字段和协议标识保持原样。
- **小说转剧本项目支持本地化目录**：新项目按当前语言创建元数据、连续性、分集和剧本文件，旧项目继续按原有路径读取。

## 稳定性

- **长任务不会因暂时没有事件而误停**：模型请求、工具和权限流程继续由各自运行时管理超时，会话层只保留绝对安全上限。
- **托管服务与 Catalog 连接更稳**：修正发布验证和 Tunnel 传输边界，减少不必要的重复部署与长连接异常。
