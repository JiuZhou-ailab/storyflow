# 最新动态

这一版重做了项目内的文件工作流，并把打开项目、显示对话和 Agent 后台初始化拆开。进入大型写作项目更轻，文件操作也更接近桌面 Finder。

## 项目文件

- **原生项目目录** — 侧边栏直接显示工作区中的真实文件和文件夹，不再依赖固定分类或旧对话导航。
- **Finder 式文件操作** — 文件和文件夹支持拖动、右键重命名、删除、新建与导入，空目录也会正常显示。
- **快速定位单个文件** — 右键某一集或其他文件即可在 Finder、Explorer 或系统文件管理器中显示，方便单独复制和交付。
- **Agent 新文件自动出现** — Agent 创建、修改或移动文件后，目录会沿用现有增量刷新与审阅标记，不会打断当前编辑。

## 打开项目与对话

- **项目内容优先可用** — 文件目录和编辑区不再等待历史会话、自动化与模型运行时全部初始化完成。
- **对话默认显示** — 进入写作项目后对话区直接可见，同时避免旧对话列表重新进入侧边目录。
- **大型项目按需渲染** — 文件树只渲染当前可见行，目录读取和默认文档加载也不再阻塞对话区出现。

## 安全与稳定性

- **文件操作限定在当前项目** — 重命名、移动、删除和 Agent 文件写入都受当前 workspace 边界约束，并阻止符号链接逃逸。
- **移动和重命名保持原子性** — 文件操作不会退化为复制后删除，冲突或非法目标会直接停止。
- **减少后台刷新压力** — 会话订阅、流式更新和文件变化刷新进一步收窄，避免进入项目后因历史数据增长而持续变慢。
