# 最新动态

这一版让桌面工作区的导航和项目起始页更连续、更安静。

## 工作区导航

- **搜索与折叠更稳定**：搜索和侧栏折叠按钮固定在窗口标题栏中，折叠导航内容后仍然随时可用。
- **保留侧栏状态**：侧栏折叠状态会被记住，下次打开应用时继续使用上次的布局。
- **状态信息更克制**：任务标题保持左对齐，只在运行、等待、报错或未读时显示状态标记。

## 项目起始页

- **入口和聊天一致**：空项目页使用与聊天开启面一致的操作卡片，创建文件、导入文件和打开 Skills 更容易区分。
- **路径保持可见**：项目根目录继续显示在起始页底部，方便确认当前正在编辑的文件夹。
