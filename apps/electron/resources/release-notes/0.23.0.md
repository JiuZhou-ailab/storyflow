# 最新动态

Storyflow 0.23.0 修复 Windows 启动问题，完善长任务生成，并新增自由对话文件工作区。

## 启动与恢复

- **安装后正常打开**：修复 Windows 上误报应用已运行、窗口没有显示便退出等问题，改善首次安装和升级后的启动。
- **启动失败有恢复入口**：按故障提供重试、查看诊断或备份配置等操作，避免静默退出；损坏的配置会保留备份，不会直接覆盖原文件。

## 长任务与生成结果

- **长文本可单独设置生成预算**：临时查询支持指定模型、思考强度、输出上限和等待时间，完整结果可直接保存为新文件。
- **截断内容明确标记**：保留部分正文并提示结果不完整，失败或取消的改写不会把半段内容当作成功结果返回。
- **子任务和长会话更可靠**：修复内置子任务的启动与扩展冲突，长会话按当前模型的上下文窗口自动压缩，原始文件和持久历史保持完整。

## 文件与技能

- **自由对话也能查看文件**：无需创建项目，即可在侧栏浏览会话附件和生成文件，使用标签页预览内容，并在窄窗口中打开文件抽屉。
- **技能发布与安装更完整**：支持预览本地技能、选择发布范围、失败后重试，并通过市场或分享链接安装到项目；同名文件不会被直接覆盖。

## 官网

- **先体验再下载**：官网加入可编辑、可审阅的写作示例，并完善分步教程与历史更新说明。
