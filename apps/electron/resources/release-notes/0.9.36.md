# 最新动态

这一版把项目管理和桌面性能排查补齐到更可用的状态：项目卡片现在可以直接重命名或移除，长会话和大文件树也减少了不必要的刷新压力。

## 项目管理

- **项目卡片支持管理菜单** — Project Hub 中每个项目都可以通过菜单重命名、移除，常用管理动作不再需要绕到工作区切换器。
- **移除项目会清理本地状态** — 移除项目会同步删除本地工作区配置、项目凭据和该项目的系统数据目录，减少残留状态。

## 性能与稳定性

- **流式输出减少列表重算** — `text_delta` 只更新当前会话正文，不再为每个流式片段重建会话元数据。
- **会话打开更轻量** — 已持久化的分支状态会直接复用，避免每次打开会话都读取 provider sidecar。
- **会话文件树限流** — 会话文件浏览最多返回 500 项，并保留用户显式展开状态，避免大目录默认全展开拖慢侧边栏。
- **文件刷新更安静** — 会话文件 watcher 合并高频变更通知，减少大输出目录下的 UI 抖动。

## 性能排查

- **新增 Electron 性能摘要工具** — `bun run perf:electron` 可以汇总 `writing.document.*`、`rpc.file.read`、`fs.searchBatch` 等调试日志。
- **补充桌面性能 QA runbook** — 新文档说明如何采集 Electron 运行时证据，区分渲染、RPC、文件系统和主进程耗时。

## 推荐使用方式

1. 在 Project Hub 的项目卡片菜单里进行重命名或移除。
2. 如果长文项目或会话文件树变慢，开启调试日志后运行 `bun run perf:electron` 查看瓶颈。
3. 移除项目目前是清理本地配置和系统状态；外部导入目录的内容策略仍按后续产品确认处理。
