# 最新动态

这一版让项目导航层级更清晰，文件操作与会话状态也会更稳定地反映真实结果。

## 更清晰的导航层级

- **项目与最近对话更醒目**：一级分组入口拥有更明确的视觉层级，方便快速定位当前工作范围。
- **子项保持紧凑**：文件、文件夹和会话仍保留清晰的缩进与轻量样式，信息密度更合理。

## 更可靠的状态同步

- **删除后立即反映真实文件树**：删除文件夹后，侧边栏不会被延迟刷新重新写回已删除内容。
- **状态切换更一致**：会话状态更新失败时会回滚到正确状态，较早的异步结果不会覆盖较新的操作。
- **并发刷新更安全**：文件操作、恢复和审阅等路径共享同一套刷新失效规则，减少过期数据回流。

## 更安全的模型访问

- **模型密钥不再随客户端分发**：登录后由服务端按账号类型签发模型访问凭证，真实上游密钥只保留在网关中。
- **模型选择已同步**：新增 GPT-5.6 Sol、Terra、Luna 与 DeepSeek V4 Flash，并保留 GPT-5.5、Gemini 3.5 Flash 和 DeepSeek V4 Pro。
- **思考强度按模型显示**：支持推理的模型在右侧提供悬停子菜单，其他模型不再显示无效入口。
