# 最新动态

下载和安装 Storyflow 占用的空间更少，内容里的链接和 MCP 工具名不再能绕过权限审批。

## 安装与更新

- **更小的安装包**：移除重复资源并压缩应用文件，保留现有语言和文档处理能力。

## 安全

- **内容链接不再执行操作**：点击回复、文档或预览中的 `craftagents://` 链接只会打开对应页面，或在确认后安装技能；创建会话、发送消息、切换权限模式、删除和授权等操作需要在应用内完成，被拦截的链接会给出提示。
- **会话不再上传到第三方站点**：会话菜单移除"分享"和"更新分享"，这两项会把完整会话上传到上游 Craft 的服务器。已分享的会话仍可打开、复制链接和停止分享；删除会话时也会尝试撤销远端分享。
- **WebUI 授权不再经过第三方中转**：在 WebUI 中连接 OAuth 来源时，授权直接回调你自己的服务器。
- **MCP 只读判定更严格**：只读规则只看工具名开头的动词，来源名称或名称中间出现的 `get`、`list` 等字样不再让写操作免审批。`query` 不再默认视为只读，需要的来源可在自己的 permissions.json 中声明。
- **探索模式真正只读**：探索模式下，Agent 不能再借 `--help`、`git -c` 或 `find`、`sed`、`sort`、`rg` 等命令的执行和写入参数运行其他程序、修改文件，也不能创建或删除 git 分支、标签，或通过 `gh api` 发起写请求。被拦截时会说明是哪个参数。

## 可靠性

- **不再因无法确认旧实例而拒绝启动**：Storyflow 改由操作系统确认上一个实例是否仍在运行，崩溃后的残留或 Windows 上进程号被复用不会再挡住启动。来自旧版本、仍无法确认的残留，可在启动提示中选择"仍然启动"；能确认仍在运行的实例始终会被保护。
- **项目不会被误标为不可用**：Windows 杀毒或索引短暂占用项目文件时会自动重试，切回窗口时会重新检查项目状态，不再整个会话都停留在"重新连接"。
- **草稿不会被意外清空**：草稿改为原子写入；草稿文件损坏时，原文件会保留为 `drafts.json.corrupt-<时间>`，启动时提示保存位置，不再被新输入覆盖。
- **重启电脑后不再提示旧实例**：旧版本留下的启动残留，只要写入时间早于本次开机，就会自动清理，不需要再选"仍然启动"。
- **窗口崩溃不再关闭整个应用**：使用中某个窗口出错只会重新加载该窗口；同一窗口短时间内反复出错时会提示，但应用和其他窗口保持打开。
- **新建对话不再静默失败**：文件被杀毒或索引短暂占用时会自动重试；仍然失败时会提示原因并提供"重试"，不会留下损坏的空会话，也不会提示你重新关联项目。
- **Agent 启动不再无限转圈**：Agent 进程启动卡住或初始化出错时，会在有限时间内给出可重试的错误。
- **帮助文档指向 Storyflow 站点**：菜单和设置里的帮助链接改为打开 Storyflow 自己的文档。

## 更新须知

名称中间含只读动词片段的 MCP 工具（例如 `delete_target`、`execute_query`）在探索模式下会被拦截，来源工具列表也不再把它们标为只读。来源 permissions.json 中只含字母的规则（如 `list`）改为只匹配以该词开头的工具名，原本依赖名称中间片段的规则（如 `issues`）需要改写为带锚点的正则（如 `^list_issues$`）。询问模式的审批行为不变；自定义的全局或工作区规则按原样生效。

探索模式下，只有"单个命令名 + `--help`"的形式（如 `ls --help`）仍免审批；带子命令或其他参数的帮助请求会被拦截，可切换到询问模式。升级时，旧的宽松帮助规则会自动从默认权限中移除。

WebUI 部署者：如果使用自己的 Google、Microsoft 或其他预先登记回调地址的 OAuth 客户端，需要在客户端里登记 `https://<你的 WebUI 地址>/api/oauth/callback`。使用动态注册的 MCP 来源不需要改动。自行构建并启用 Slack 授权时，需要额外配置 `SLACK_OAUTH_RELAY_URL`，指向你自己运营的 HTTPS 中转服务。
