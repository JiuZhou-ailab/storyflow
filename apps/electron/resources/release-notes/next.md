# 最新动态

Storyflow 0.10.2 补齐了受邀邮箱的注册与登录流程。外部成员现在可以通过邮件验证码完成身份验证并加入 Storyflow，已有飞书登录不受影响。

## 受邀邮箱登录

- **验证码直接完成注册**：受邀成员创建账号后输入六位邮件验证码，即可完成验证并自动登录。
- **邀请无需额外口令**：邀请与邮箱绑定，不再要求用户保存或输入另一组邀请码。
- **登录状态可安全恢复**：重启 Storyflow 后仍可继续使用托管模型，无需频繁重新登录。

## 访问安全

- **成员权限及时生效**：账号被移出组织后无法继续刷新托管模型权限，已有短期权限也会在十五分钟内失效。
- **飞书登录保持稳定**：现有飞书账号、企业成员校验和托管模型权限均沿用原有流程。
