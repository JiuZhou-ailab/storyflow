# 最新动态

这一版把项目还原为真实文件夹，让任务、文件和模型运行都更直接、更稳定。

## 项目与任务更直接

- **项目就是文件夹**：导入或新建项目时直接使用所选目录，不再额外创建 `workspace-xxx` 子目录。
- **新任务继承当前项目**：在项目中点击“新建任务”会显示当前项目名称；关闭项目上下文即可切换为自由对话。
- **侧边栏更安静**：统一字体、行高、间距和层级，降低侧边栏与主区域的视觉反差，同时限制默认展示数量。

## 原生文件工作区

- **真实目录结构**：侧边栏按文件系统展示目录、文本、JSON、图片和视频；进入项目时只读取目录元数据，不再自动打开首个文件。
- **图片和视频在标签页预览**：媒体文件直接在当前文件标签页中打开；大视频按需流式读取，避免整文件进入内存导致界面卡死。
- **历史记录保持轻量**：项目版本快照只跟踪可编辑的 Markdown 和文本文件，不再把视频、图片或 Storyflow 内部文件写入历史。

## 模型与长会话

- **模型能力统一管理**：桌面端和模型网关共用同一份托管模型目录，模型切换与思考等级只展示实际支持的选项。
- **上下文占用更准确**：输入框显示当前上下文占用，而消息指标明确区分单轮累计输入，长会话状态更容易判断。
- **运行时更简洁稳定**：所有模型统一经过 Pi 运行时，减少重复的分支、压缩和工具事件适配逻辑。
