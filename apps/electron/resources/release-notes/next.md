# 最新动态

这一版让 Skills 原生适配 Pi 与开放 Agent Skills 生态，并补齐对话与写作工作区的关键交互。

## Skills 原生适配

- **用户与项目 Skill 各归其位**：用户 Skill 可跨项目复用，项目 Skill 可随仓库共享；技能栏与 Agent 使用 Pi 的同一份解析结果。
- **AnySearch 开箱即用**：默认提供网页搜索、垂直领域搜索、批量查询与页面正文提取；无需密钥也可匿名使用。
- **可发现开放 Skills**：新增 Find Skills 默认能力，可检索并审查 skills.sh 与 GitHub 上的 Skills，并使用 Skills CLI 或 Storyflow Market 安装。
- **无需重启刷新**：`.pi/skills`、`.agents/skills` 和用户 Skill 目录发生变化后，技能栏会自动刷新。
- **共享 Skill 也能正常删除**：使用中文名称的 `.agents/skills` 不再因目录名校验而删除失败；打包安装的 Skill 仍交由包管理器卸载。
- **Skill 内容跟随用户语言**：Skill Creator 会按明确目标语言、已有内容语言或用户主要输入语言生成说明与测试内容，技术标识符保持原样。
- **小说转剧本全面中文化**：Skill 显示名、操作说明、方法参考、测试用例和命令帮助统一使用中文，并移除旧后端相关提示；机器标识符与项目文件协议保持不变。

## 对话操作更可靠

- **新建自由对话直接开始**：点击新建按钮会创建新的自由对话，而不是只回到历史列表。
- **首条消息也能重新编辑**：没有可分支历史时，仍可安全重写第一条用户消息。
- **结构化追问更紧凑**：选择题和补充输入不再占用过多对话空间。
- **运行权限只保留两档**：可选择“直接运行”或“询问运行”，并移除顶部的待办与信息按钮。
- **移除待办展示**：对话不再额外解析和渲染 Todo List，历史工具事件仍可正常查看。

## 写作工作区更顺手

- **单击替换，双击新增标签**：浏览文件时可快速复用当前标签，也能保留多个打开的文档。
- **加号回到工作区开始页**：右侧文件标签栏的加号会打开新建、导入与 Skill 入口，并保留已打开的文档标签。
- **差异审查自动选择可见位置**：工作区可用时在右侧审查；紧凑或空项目场景会回到完整对话视图。
