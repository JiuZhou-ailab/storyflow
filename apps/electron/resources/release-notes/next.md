# 最新动态

这一版重新整理侧边栏的项目层级，并升级托管模型请求链路。

## 项目层级更清晰

- **父子层级重新对齐**：项目名称与其会话历史形成稳定的两级缩进，移除重复的会话图标和树形边框。
- **项目会话可展开或收起**：默认显示最近五条，按需展开全部记录，不再让单个项目占满侧边栏。
- **操作只在需要时出现**：分组箭头、新建按钮和项目操作在悬停、键盘聚焦或菜单打开时显示。
- **运行状态更直观**：正在加载或运行的项目与会话使用统一的转圈状态，未读状态仍保持原有提示。

## 托管模型连接

- **默认使用 Responses API**：新版桌面通过 OpenAI Responses 协议访问托管模型，旧版桌面的 Chat Completions 请求继续兼容。
- **故障定位不暴露内容**：网关记录请求耗时、上游状态和关联标识，不写入对话正文或访问凭据。
