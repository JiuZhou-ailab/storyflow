# 最新动态

这一版把写作项目目录收拢成真正的“所见即所得”：项目根目录默认只放正文、全局和自由区等内容文件，系统状态、会话、标签、技能和配置统一迁入隐藏的 `.craft-agent` 目录。

## 写作项目目录

- **项目根目录更干净** — 新建短篇项目默认只展示 `正文/`、`全局/`、`自由区/`；系统配置、会话记录、标签、状态、技能和 sources 不再挤在用户内容目录旁边。
- **自由创作只保留事实文件夹** — 自由创作不再预建正文、自由区和参考资料，只创建 `全局/`，用于沉淀项目说明、创作要求和稳定事实。
- **旧项目会自动迁移** — 已存在于根目录的 `config.json`、`sessions/`、`labels/`、`statuses/`、`skills/`、`sources/` 等状态文件会迁移到 `.craft-agent/`，不会移动正文、全局、自由区等创作内容。
- **文件操作限制在当前项目内** — 读写、删除、建目录和搜索都按当前 workspace 校验，避免跨项目误读写。

## 推荐使用方式

1. 在侧边栏把项目 id 展开后，优先把用户可编辑内容放在 `正文/`、`全局/`、`自由区/`。
2. 不需要手动维护 `.craft-agent/`；它是系统状态目录，默认可以忽略。
3. 自由创作项目先在 `全局/` 记录事实，等需要正文或草稿区时再按需新增目录。
