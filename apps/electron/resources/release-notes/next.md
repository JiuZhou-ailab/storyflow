# 最新动态

这一版让项目打开得更快，侧栏状态更准确，并减少了 Windows 首次安装时的额外配置。

## 项目与会话

- **打开项目不用再等全部历史**：进入一个项目时只准备当前项目的会话，其他项目继续在后台加载，首次查看会话或搜索都更快。
- **侧栏状态及时同步**：任务标题、运行状态和未读信息会随当前会话更新，自由对话不会再混入项目列表。
- **飞书头像直接显示**：使用飞书登录后，侧栏账户入口会显示你的头像。

## 模型

- **DeepSeek 成为默认模型**：新用户可以直接从 DeepSeek 开始，Claude 的托管连接也恢复正常。

## Windows

- **首次安装少一步配置**：安装 Storyflow 时会尝试一并准备 Git for Windows；如果系统无法自动安装，原有引导仍会告诉你如何处理。
