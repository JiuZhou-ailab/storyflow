# 最新动态

这一版把 Skills 收敛为全局能力，并补齐对话与写作工作区的关键交互。

## Skills 全局复用

- **一处安装，所有项目可用**：Skills 统一存放在全局目录，不再为每个项目维护重复副本。
- **AnySearch 开箱即用**：默认提供网页搜索、垂直领域搜索、批量查询与页面正文提取；无需密钥也可匿名使用。
- **创建与校验更一致**：Skill 创建、导入、校验和 Agent 加载现在共享同一份全局定义。

## 对话操作更可靠

- **新建自由对话直接开始**：点击新建按钮会创建新的自由对话，而不是只回到历史列表。
- **首条消息也能重新编辑**：没有可分支历史时，仍可安全重写第一条用户消息。
- **结构化追问更紧凑**：选择题和补充输入不再占用过多对话空间。

## 写作工作区更顺手

- **单击替换，双击新增标签**：浏览文件时可快速复用当前标签，也能保留多个打开的文档。
- **差异审查自动选择可见位置**：工作区可用时在右侧审查；紧凑或空项目场景会回到完整对话视图。
