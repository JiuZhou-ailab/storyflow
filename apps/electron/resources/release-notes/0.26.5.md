# 最新动态

这一版加入 Gemini 4 Hydrogen，也改进了聊天过程、项目切换和 Skills 市场刷新。

## 聊天与模型

- **新增 Gemini 4 Hydrogen**：可在模型选择器的 Gemini 分组中选择 Hydrogen。
- **聊天过程按完整行滚动**：生成时只滚动显示最新的完整行，回复结束后显示步骤摘要和完整正文。
- **步骤详情默认收起思考原文**：先看一行中文摘要，点开即可阅读完整原文。
- **空输入框可建议下一句**：回复结束后，有建议时按 Tab 填入草稿，再编辑或发送。
- **紧凑聊天显示实际回复模型**：首选模型处于冷却期时，聊天会说明为何用了其他模型。
- **托管模型错误提示更明确**：区分需要重新登录、权限已取消和服务暂时不可用，访问恢复后会提示重新发送。
- **GPT 和 Gemini 会话更容易继续**：GPT 推理内容失效时会尝试自动恢复，Gemini 续接带工具调用的历史时更稳定，部分网关连接错误也能按临时故障重试。

## 桌面操作与权限

- **新对话记住上次手动选择的运行方式**：从桌面新建对话时沿用上次选择，从外部链接或消息网关创建时使用项目默认方式。
- **快捷键和中文提示更好找**：侧边栏的「新建任务」会显示快捷键，权限确认和部分桌面按钮补齐了中文。

## 写作、项目与 Skills

- **切回已打开的项目更快**：先显示上次加载的目录，再检查文件更新。
- **Skills 市场可主动刷新**：列表加载失败后可直接重试。
- **写作编辑器和 Skill 文档安全更新**：更新了 Markdown 编辑器及 Skill 文档校验、加载所用的组件。

## 会话恢复、自动化与自托管

- **恢复会话时保留完整消息**：写入中断后，应用会从完整的会话文件或备份恢复。
- **Webhook 重试保留待发任务**：保存队列失败时保留原有任务，供后续重试。
- **恢复 Server 镜像构建**：从源码构建时可以按锁文件安装依赖。
