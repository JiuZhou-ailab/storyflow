# 最新动态

这一版打开更快、用起来更稳，也更安全。

## 这次更新

- **打开更快**：会话多、项目大时，启动和展开目录都更快。
- **对话更快**：多轮对话和中止后继续，不再重新处理整段内容。
- **不再意外退出**：窗口出错只重载该窗口，草稿也不会丢。
- **项目打不开会说明原因**：悬停查看原因，右键可重新关联或打开文件夹。

## 更快

- **启动更快**：会话很多的项目，恢复列表更快。
- **目录更快**：首次展开写作目录更快，切换项目时不会重复加载。
- **对话更快**：切换权限、在外部改文件或中途补充指令后，仍会复用之前的对话缓存。
- **MCP 来源不拖慢对话**：连不上的来源会稍后自动重试，单个来源最多等待 60 秒。
- **安装包更小**：去掉了重复资源，下载和安装更省空间。

## 更稳

- **启动不再被旧实例挡住**：崩溃或重启电脑后能正常打开；无法确认时，可以选"仍然启动"。
- **窗口出错不关闭应用**：只重新加载出错的窗口，其他窗口不受影响。
- **草稿更安全**：草稿文件损坏时会保留原文件并告诉你位置，不会被新内容覆盖。
- **新建对话不再静默失败**：文件被杀毒软件短暂占用时会自动重试，仍然失败会提示并可重试。
- **Agent 不再无限转圈**：启动卡住时，会在有限时间内报错并可以重试。
- **项目不会被误标为不可用**：切回窗口时会重新检查；文件夹被移走时，悬停可以看到原因和原位置。
- **右键项目更好用**：可以在访达或资源管理器中打开项目文件夹，也能直接重新关联。
- **取消的更新可以再装**：因文档未保存而取消安装后，可以再次安装。
- **保存时会话不会消失**：会话保存过程中，列表也能正常显示。

## 更安全

- **链接不会替你执行操作**：内容里的链接只会打开页面；创建会话、删除、授权等操作需要你在应用里完成。
- **会话不会上传到第三方**：移除了"分享"；已分享的会话仍可打开和停止分享。
- **审批更严格**：探索模式真正只读，MCP 工具只按名称开头判断是否只读。
- **附件和图标更安全**：只读取你选中的附件，图标中的脚本会被清除。
- **帮助链接指向 Storyflow**：菜单和设置中的帮助会打开 Storyflow 自己的文档。

## 更新须知

- **探索模式会多拦截一些操作**：例如名称中间带 `get`、`list` 的写操作工具，以及带子命令的 `--help`。需要时切换到询问模式即可。
- **自定义过 MCP 权限规则？** permissions.json 中只含字母的规则（如 `list`）现在只匹配以它开头的工具名，其他写法请改成正则（如 `^list_issues$`）。
- **自行部署 WebUI？** 自有 OAuth 客户端需要登记回调地址 `https://<你的 WebUI 地址>/api/oauth/callback`；启用 Slack 授权需要配置 `SLACK_OAUTH_RELAY_URL`。
