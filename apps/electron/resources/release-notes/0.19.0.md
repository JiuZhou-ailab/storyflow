# 最新动态

Storyflow 0.19.0 升级了 Agent 内核并加强了历史数据保护，会话更稳定，历史项目与对话始终可用。

## 稳定性

- **修复插件冲突导致会话无法启动**：全局安装的 Pi 插件与内置工具重名时不再报错中断，内置工具自动优先，其余插件功能照常可用。
- **修复对话卡在"思考中"**：升级 Agent 内核到 Pi 0.84.4，修复长任务中途压缩被跳过、超大工具结果直发模型和截断响应误判导致的转圈不结束问题。
- **会话恢复更可靠**：修复恢复历史会话时因文件结尾缺少换行导致后续记录损坏的问题。

## 数据安全

- **历史对话保护加强**：建立持久化数据读取契约，旧版本创建的项目和会话在任何升级后保持可见、可打开，并有专门测试防止回归。
